# Akira

Akira wraps [chiaki-ng](https://github.com/streetpea/chiaki-ng) and [Pylux](https://github.com/ForWard-Technologies-LLC/Pylux) for remote play and PS Cloud streaming respectively.

Start here: **[Registering and Connecting](./setup/registering.mdx)**.

This used to live in-tree in chiaki-ng, where I originally updated chiaki-ng to be compatible for the Nintendo Switch. Dealing with user support however, got too exhausting to deal with.

You'll notice that Akira's github cant be interacted with entirely for GitHub users with a < 1 year account and issues are disabled. This is a side effect of the above. 

Support takes place on chiaki-ng's discord server where users are expected to turn up with proper reproduction steps, logs, and possibly help to run test builds if I am unable to reproduce the error on my end.



## Network requirements

Your network matters more than anything else here.

:::warning
- **You need a good wifi network.** A 5 GHz network on its own isn't enough. You need a strong signal to it.
- **The access point should have a wired backhaul.**
- **Your router should not be dropping packets under load.**
- **Wire your PS4/PS5 with ethernet.** 
- **Your network must be stable and not dropping packets or under heavy load.**
:::

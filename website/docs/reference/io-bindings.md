# I/O Bindings

:::info
As of v0.4.0, akira shows these mappings in the button-configuration menu, and you can remap them there. This page stays for reference.
:::

## Button mappings (Switch to PS4/PS5)

| Nintendo Switch   | PlayStation                               |
|-------------------|-------------------------------------------|
| A                 | Circle (or Cross if "Invert A/B" enabled) |
| B                 | Cross (or Circle if "Invert A/B" enabled) |
| X                 | Triangle                                  |
| Y                 | Square                                    |
| D-pad             | D-pad                                     |
| L                 | L1                                        |
| R                 | R1                                        |
| ZL                | L2                                        |
| ZR                | R2                                        |
| Left Stick Click  | L3                                        |
| Right Stick Click | R3                                        |
| Plus (+)          | Options                                   |
| Minus (-)         | PS Button                                 |
| Left/Right Sticks | Left/Right Sticks                         |

## Touchpad (via Switch touchscreen)

| Action                        | Result                  |
|-------------------------------|-------------------------|
| Touch center area             | Touchpad swipe/movement |
| Touch edge (within 5% border) | Touchpad button press   |

## Motion controls (six-axis)

| Data      | Mapping                              |
|-----------|--------------------------------------|
| Gyroscope | Passed through (with axis remapping) |

## Custom

Hold **-** for 3 seconds to open the disconnect/debug menu.
